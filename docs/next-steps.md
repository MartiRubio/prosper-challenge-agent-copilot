# Next steps

The editor, the branching canvas, and the copilot are in the tree.

The copilot is one loop. A chat beside the canvas proposes small changes, and you keep or discard each one on the graph. Flagged calls open that same review. A finished test call is written to that agent's file under logs/calls.

The catalog owns a function's fields. An edge stores the function name and the step it enters. Renaming a function rewrites that name on the other saved agents. Leaving an agent with unsaved edits asks first. Save checks that every step has a task and that every function is in the catalog.
